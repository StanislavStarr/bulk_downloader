# Bulk Downloader for Ya Disk

Независимое расширение для массовой загрузки файлов из **собственного аккаунта Яндекс Диска** в Chrome. Яндекс и разработчики сервиса не связаны с этим расширением.

## Установка

1. Открой `chrome://extensions` и включи режим разработчика.
2. Выбери **Load unpacked / Загрузить распакованное** и укажи папку с `manifest.json`.
3. Открой личную папку на `disk.yandex.ru/client/disk`, обнови страницу, затем открой расширение.
4. Нажми **Собрать файлы**, затем **Скачать все**.

Для обновления установленной вручную версии скопируй новые исходники **в ту же папку**, нажми Reload в `chrome://extensions` и обнови страницу Яндекс Диска. При сохранении идентификатора расширения существующая локальная очередь остаётся доступной.

## Возможности

- Сканирование файлов **в текущей открытой папке** и очередь скачивания; вложенные папки пока не сканируются рекурсивно.
- Получение временных ссылок через собственную браузерную сессию Яндекс Диска; отдельный OAuth-токен не нужен.
- До трёх параллельных загрузок; ошибки файлов не останавливают обработку остальных.
- Просмотр прогресса, статусов, фильтр ошибок, 50 файлов на странице и ручные повторы.
- CSV-журнал по текущей папке: экспорт и отдельная кнопка **Очистить журнал**. Очистка удаляет только локальные события текущей папки, а не файлы, очередь, историю Chrome или уже экспортированные CSV.
- Относительная подпапка сохранения в стандартном каталоге Chrome. Основную папку можно поменять в `chrome://settings/downloads`.
- На время скачивания можно скрывать панель загрузок Chrome (по умолчанию включено). Это влияет на профиль браузера целиком; расширение восстанавливает панель при завершении/остановке.
- Дополнительно можно удалять из истории Chrome прерванные загрузки, инициированные расширением (по умолчанию выключено).

## Ограничения и безопасность

Работает с личными файлами, доступными в текущем веб-интерфейсе. Используется **недокументированный внутренний API Яндекс Диска**, который может измениться или временно не работать. Статус `unconfirmed` не означает, что Chrome не создал загрузку — проверь `chrome://downloads` перед ручным повтором.

Расширение просматривает имена файлов и необходимые значения авторизованной сессии (`sk`, `connection_id`) только на `disk.yandex.ru`. Они используются для получения ссылок на файлы в пределах текущей браузерной сессии, не включаются в CSV и не отправляются на отдельный сервер разработчика. Очередь, настройки и журнал сохраняются локально в браузере; сессионные ключи — в `chrome.storage.session`.

Удаление журнала не удаляет файлы. Внимательно проверь параметры браузера до массового скачивания.

Политика конфиденциальности — `PRIVACY_POLICY.md`. Публикуемую версию политики необходимо разместить на доступной по HTTPS странице и указать её адрес в Chrome Web Store.
