# Chrome Web Store — материалы карточки

## Название
Bulk Downloader for Ya Disk

## Краткое описание
Массовое скачивание файлов из личного Яндекс Диска с очередью, прогрессом и CSV-журналом.

## Полное описание
Скачивайте файлы из открытой папки личного Яндекс Диска без ручного скачивания по одному.

Возможности:
- Сбор файлов из текущей папки и очередь скачивания.
- До 3 параллельных загрузок через временные ссылки.
- Продолжение обработки после ошибок и ручной повтор.
- Статусы, прогресс и постраничный просмотр файлов.
- Экспорт и очистка локального CSV-журнала.
- Выбор подпапки стандартного каталога загрузок Chrome.
- Настраиваемое скрытие панели загрузок во время пакетной работы.

Требуется действующая сессия личного Яндекс Диска в браузере. Вложенные папки пока не обходятся автоматически. Используется внутренний интерфейс Яндекс Диска, который может измениться. Расширение не является официальным продуктом Яндекса.

## Single purpose (для Privacy Practices)
Batch-download files from a folder in the user's own Yandex Disk account, track progress, and recover from individual download failures.

## Обоснование разрешений
- `storage`: локальная очередь, статусы, настройки, журнал и сессионные параметры, нужные для скачивания.
- `downloads`: запуск, отслеживание и отмена загрузок; опциональное удаление прерванных записей из истории.
- `downloads.ui`: временное скрытие и восстановление панели загрузок Chrome по пользовательской настройке.
- `alarms`: восстановление и продолжение работы очереди после остановки service worker Chrome.
- `tabs`: определение текущей открытой папки Яндекс Диска и связь с вкладкой.
- `webRequest`: чтение необходимых параметров сессии в запросах к API Яндекс Диска для получения временных ссылок на файлы.
- `host_permissions https://disk.yandex.ru/*`: доступ только к веб-клиенту Яндекс Диска.

## Privacy Practices
На странице магазина необходимо правдиво указать обработку файловых имён, веб-адреса папки, диагностических данных загрузок и краткоживущих сессионных параметров. Данные не передаются разработчику; запросы идут к сервису Яндекс Диска. Не отмечай отсутствие обработки пользовательских данных, поскольку расширение работает с метаданными файлов и сессией.

## Перед отправкой на проверку
1. Укажите публичный email поддержки и замените заглушки в `PRIVACY_POLICY.md`.
2. Разместите политику конфиденциальности по HTTPS; укажите URL в Chrome Web Store Dashboard.
3. Сделайте **реальный** скриншот popup во время работы на тестовой папке, без личных имён и файлов. Требуемый размер скриншота для карточки — 1280x800 либо 640x400.
4. Добавьте небольшую промо-картинку 440x280 (если требуется интерфейсом публикации) и 128x128 PNG icon из `icons/`.
5. Протестируйте установленный `webstore-upload.zip` в Chrome перед загрузкой в магазин.
6. Зарегистрируйтесь в Chrome Web Store Developer Dashboard, загрузите ZIP, заполните Store Listing, Privacy и Distribution, затем отправьте на проверку.
7. Проверка магазина не гарантирована: используется недокументированный API и доступ к авторизованной сессии, поэтому проверяющие могут запросить объяснение или отказать.
